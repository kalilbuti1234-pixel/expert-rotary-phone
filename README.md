# expert-rotary-phone (سكنار 1.0)

نسخة تجربة ويب بسيطة لمشروع "سكنار 1.0".

ما تم إضافته
- index.html — صفحة تجربة عربية بسيطة.
- style.css — تنسيقات الواجهة.
- script.js — منطق بسيط للوحة الأرقام ومحاكاة "الاتصال".

كيفية العرض محلياً
1. استنخِ المستودع:
   git clone https://github.com/kalilbuti1234-pixel/expert-rotary-phone.git
   cd expert-rotary-phone

2. افتح index.html مباشرة في المتصفح أو شغّل سيرفر بسيط:
   npx serve .
   أو
   python -m http.server 8000
   ثم افتح http://localhost:8000

نشر على الويب (GitHub Pages)
1. اذهب إلى إعدادات المستودع (Settings → Pages).
2. اختر الفرع "main" والمجلد "/ (root)" ثم اضغط Save.
3. انتظر دقائق، ثم سيكون الموقع متاحًا على: https://kalilbuti1234-pixel.github.io/expert-rotary-phone/

نشر باستخدام Vercel/Netlify
- ربط المستودع في لوحة Vercel أو Netlify وستنشر الصفحة تلقائياً (Static site).

إذا تريد تخصيص المحاكاة (صوت طلب، تصميم دائرة دوارة، ربط بخدمة حقيقية) أخبرني بالميزات وسأضيفها.
